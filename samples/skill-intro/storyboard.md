# Storyboard — skill-intro (30 s · 7 scenes · 64 beats @ 128 BPM)

Style: flat pop with a playful neo-brutalist edge — a saturated colour per scene, chunky black outlines and hard offset shadows on sticker-like cards, huge Archivo Black-weight grotesk, `eBack` bounces, `slam` without RGB split, diagonal colour-block wipes, electro groove at 128 BPM — because the user asked for a bold, playful flat-pop look (not the console), the audience is developers skimming a GitHub README where a loud, fast teaser has to stop the scroll, and the piece itself should visibly prove the skill can leave its default dark console.

Metaphor: **a CI pipeline run** — the developer's own world. The film is one run of the skill's pipeline: a row of stage pills in the HUD (`brief → build → check → ship`) fills as scenes pass, kickers read like job names (`$ run · brief`), passed stages get a check stamp. Body copy stays plain.

Audience: developers browsing GitHub. Languages: en (default) + ko. Call to action: https://github.com/JakeB-5/motion-graphic-skill (dock button + repo card on the last frame).
